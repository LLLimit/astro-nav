# 两级分类

## 管理方式

1. 在后台「分类管理」点击「添加一级分类」。一级分类出现在侧边栏，并在首页拥有独立分区。
2. 在一级分类右侧点击「添加二级分类」。例如「AI 工具」下添加「聊天对话」「绘画」「编程」。二级分类只出现在该分区的顶部标签栏。
3. 添加／编辑网址时先选择「一级分类」，再选择「二级分类」。也可以选择「不细分，直接放入一级分类」。快速导入的分类选择器同样支持二级分类。
4. 修改二级分类的「上级分类」可以将它和所包含的网址一起移到另一个一级分类下；没有二级分类的一级分类也可以改为二级分类。

二级分类栏显示「全部」及手动创建且设为显示的二级分类，默认选中「全部」，不自动生成「未细分」标签。「全部」包含直接归属一级分类及其可见二级分类的网址。没有二级分类时，直接显示一级分类的网址。标签切换只改变该分区；站内搜索仍搜索所有可见分类下的网址，包括当前标签未显示的网址。标签栏支持左右方向键和 Home／End；小屏幕可横向滚动。

每个一级分类和二级分类标签默认最多显示 15 个网址，超过时在分区底部显示「展开全部」，点击后显示全部网址，再点击「收起」恢复 15 个。每个标签分别记住本次页面访问的展开状态；不超过 15 个时不显示按钮。桌面宽度下使用五列三行，小屏幕保持自适应列数。折叠仅影响展示，站内搜索仍能找到折叠的网址。

一级分类按排序值排列，二级分类在其上级范围内按排序值排列；网址保持已有的置顶、推荐、排序规则。排序均为非负整数。一级分类关闭「在首页显示」后，其所有二级分类和网址一并隐藏；单独隐藏二级分类不会影响同级分类。删除有二级分类的一级分类前，需要先移动或删除子分类，防止误删。

## 覆盖升级

本次新增迁移 `drizzle/0004_two-level-categories.sql`，为分类添加可空的 `parent_id`、外键和查询索引。原有分类自动保持为一级分类，原网址归属不变。

覆盖源码时保留服务器的 `.env` 和 `data/`。进入原部署目录执行：

```bash
pnpm install --frozen-lockfile
pnpm db:migrate
pnpm build
```

完成后在宝塔重启原 Node／PM2 项目。无需修改数据库连接、域名、启动文件或端口。
